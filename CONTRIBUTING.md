# Contributing to Arras

Thanks for helping improve Arras.

Before opening a pull request, please open or join an issue for substantial changes. Keep changes focused and preserve Arras's native-first approach: prefer Apple frameworks, minimal dependencies, low resource usage, intentional customization, root-cause fixes, and no unnecessary data collection.

For code changes:

1. Build and test on a supported macOS version.
2. Add or update tests when practical.
3. Keep generated project files in sync with `project.yml`.
4. Describe what changed, why, and how you tested it in the pull request.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report security issues through [SECURITY.md](SECURITY.md), not a public issue.
